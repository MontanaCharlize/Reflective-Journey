## 补齐的社区流程

| 页面 | 本版行为 |
| --- | --- |
| 发现思考 | 搜索公开的问题、成果文字或作者；按独立开始 / 接续成果筛选；游标分页 |
| 我的收藏 | 服务端保存，只对当前账户可见；刷新和重登录后保留；撤回内容不会出现 |
| 作者主页 | 展示名称、简介、公开成果、公开接续数量；不公开登录账号和运营权限 |
| 我的分享 | 分页查看全部 / 公开中 / 已撤回；不再截断于前 100 张 |
| 卡片详情 | 最近八层可公开来源路径、接续成果数量与分页、收藏、分享链接、内容反馈 |
| 公开卡片编辑 | 只编辑公开副本；逐项预览和确认；取消字段即移除；版本冲突提示刷新 |
| 接续提醒 | 他人自愿发布接续成果后生成；登录即显示未读数；可逐条 / 全部已读 |
| 我的反馈 | 本人查看提交内容、处理状态和运营说明，其他普通账户不能读取 |
| 社区内容处理 | 配置的运营账户查看待处理 / 已处理反馈，保留内容或停止公开，并给出说明 |
| 账户 | 编辑公开名称与简介，进入公开主页、收藏、分享、提醒和反馈 |

接续仍从空认知状态开始，只带问题与来源信息。完整对话、随手记、草稿和认知分析不进入公开卡片。收藏不会变成公开赞数，接续数量用于理解思考路径。

## 关键一致性规则

- 发布卡片与生成接续提醒在同一个数据库事务中完成。相同请求重试不会重复发提醒，自己接续自己不发提醒。
- 编辑公开卡片需要提交当前版本，服务器在事务内检查。旧窗口不能覆盖新窗口的修改，来源关系也不能借编辑被替换。
- 更新卡片只改变公开副本，私人原始对话及他人的接续成果不被改写。来源链接展示当前可公开版本；不会保存或公开历史已移除字段。
- 撤回或运营停止公开后，发现、收藏、作者成果、来源路径和相关提醒都会过滤不可公开卡片；作者在自己的分享中保留副本。
- 提醒、收藏、本人反馈都从 Cookie 身份取用户，沿用旧页面身份检查和 Origin 校验。普通账户不能通过伪造角色进入运营接口。
- 用户补充已处理反馈后，该反馈重新进入待处理。运营页面提交时也校验反馈时间，避免处理已经变动的旧版本。
- 连接失败和超时有可重试的中文提示；公开资料未成功读取前不能保存空白覆盖已有简介。

公开后的文字可能已被他人复制，撤回与编辑无法收回别人的副本。当前私密思考仍只在各自浏览器保存，未新增私密对话云同步。

## 数据升级

保留 V0.6 的 users、sessions、cards 等原表，增加以下表和必要索引，不清空旧数据：

- profiles：公开简介。
- bookmarks：账户与卡片的私密收藏关系。
- card_meta：公开副本版本和更新时间。
- community_notifications：接续提醒及已读状态。
- report_reviews：反馈处理结果、说明、运营者与时间。

旧卡片默认从版本 1 开始。测试从仅包含旧表的数据库启动，验证旧账号、旧卡片仍可用；重新启动后新资料、收藏、卡片版本与提醒仍保留。

运行环境仍为 Node.js 24.13 或更新版本、单实例 Node 服务与持久 SQLite。部署前应备份数据库，更新程序后重启服务。仅替换静态 dist 无法新增后端能力。

## 运营权限与命令行

在服务端环境配置中指定已有账户的登录账号名，例如：

```env
COMMUNITY_MODERATOR_USERS=operator_one,operator_two
```

留空时没有网页运营账户。本次只在独立验收库中给合成测试账户设置权限，没有修改真实配置或给真实账户授权。修改配置后重启服务，用户重新打开账户页可同步权限。

正常账户的运营标记由服务器返回，后端每次操作仍根据配置校验。运营处理可以停止公开，不能编辑别人的判断或读取其私密对话。

服务器本机也可执行：

```bash
npm run moderate -- reports pending
npm run moderate -- reports resolved
npm run moderate -- review <反馈ID> keep "核查后的处理说明"
npm run moderate -- review <反馈ID> withdraw "停止公开的处理说明"
```

反馈列表返回 nextCursor，可作为 `reports <状态> <游标>` 继续读取。原 `withdraw <卡片ID> "原因"` 保留为直接停止公开入口；若要完整记录反馈处理，应使用 review。

## 新增接口

| 方法和路径 | 功能 |
| --- | --- |
| POST `/api/account/profile` | 保存自己的公开名称、简介 |
| GET `/api/community/authors/:id`、`/:id/cards` | 作者公开资料与成果分页 |
| GET `/api/community/bookmarks` | 当前账户收藏分页 |
| POST `/api/community/cards/:id/bookmark` | saved 布尔值，幂等设置收藏状态 |
| POST `/api/community/cards/:id/edit` | question、fields、revision，冲突返回 409 |
| GET `/api/community/cards/:id/branches` | 接续成果分页 |
| GET `/api/community/notifications` | 提醒分页、未读数量 |
| POST `/api/community/notifications/read` | ids 数组或 all=true，限当前账户 |
| GET `/api/community/my-feedback` | 本人反馈与处理结果分页 |
| GET `/api/community/moderation/reports` | 运营反馈队列分页 |
| POST `/api/community/moderation/reports/:id/resolve` | resolution、note、expectedAt |

发现列表支持 q、kind；个人分享支持 q、status；分页支持 cursor、limit。筛选与访问范围绑定游标，不能将其他范围的游标直接混用。
