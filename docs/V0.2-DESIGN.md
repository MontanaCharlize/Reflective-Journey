# 反思之旅 V0.2 设计冻结

## 产品定义

不是知识库，不是 AI 聊天机器人，也不是固定学习表单。

**从用户自己的问题出发，判断下一步怎样介入最能促进他的思考。**

## 核心前台体验

用户提出问题 → 系统选择一个认知介入 → 用户继续回答 → 系统重新判断下一步 → 用户主动结束 → 整理自己的当前判断。

## 后台认知框架

“先思考 → AI 介入 → 验证 → 修正 → 反思”继续存在，但不直接暴露为固定阶段。

## V0.2 认知类型

- 因果解释
- 证据判断
- 决策权衡
- 问题求解
- 概念理解
- 多视角判断
- 自我反思
- 探索性思考

## 视觉原则

- 安静
- 聚焦
- 渐进
- 大留白
- 人的内容比系统提示更有视觉重量
- 禁止 SaaS 卡片墙
- 禁止多栏功能卖点
- 禁止聊天气泡成为主界面
