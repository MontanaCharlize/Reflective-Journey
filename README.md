# 反思之旅 V0.10.0

反思之旅是一款帮助用户梳理问题、检查判断依据并回看思考过程的 Web 应用。AI 根据对话参与理解和方向选择，用户可以纠正、换方向或暂停，最后由本人确认成果和公开范围。

V0.10 补齐可展开的社区思考路径，以及成果、个人历史与公开副本之间的返回入口。修复运营用户名抢注与旧反馈决定下架新版内容的问题。详见 [社区路径与成果回流](docs/COMMUNITY-V0.10.md)。

![虚构验收场景中的来源与成果回流](docs/community-v010-preview.png)

仓库提供源码。Windows 运行包可双击启动；源码需要下面的安装与构建步骤。源码测试和运行包命令是不同入口，不能在运行包的“拒绝测试”提示上计作测试通过。

V0.9.1 修正运行版的命令入口：dev、serve、start 统一启动构建好的应用，重复启动可识别已有服务；测试和构建会明确要求使用源码包，避免“0 项测试”和缺配置的误导。运行包有独立说明和无开发依赖的包配置。

V0.9 以 V0.8.1 为主干，保留 AI 共同决策、社区和成果导图，修正并迁入健康检查、Docker、Caddy、systemd 与数据库备份恢复工具。最终材料分为源码包和 Windows 运行包，均排除密钥、个人记录和测试数据库。运行、恢复与提交方法见 [本地提交说明](docs/LOCAL-RELEASE.md)，可直接填写的名称与简介见 [参赛简介](docs/SUBMISSION-INTRO.md)。

V0.8.1 在成果页加入「思维导图」，从已确认的成果和验证回看生成，可展开、折叠、移动、缩放并导出 PNG / SVG。不会请求模型或把笔记、完整对话加入导图；未填写的内容不生成节点。详情见 [成果思维导图](docs/RESULT-MIND-MAP.md)。

V0.8 修正核心对话：AI 根据整段对话决定当前目标、回应和下一问，不再由本地固定清单选动作、模型只负责改写。已经明确的选择不会继续索要；模型失败时显示失败原因并保留原话，只有用户主动选择「本地提纲」时才使用规则模板。旧记录可以点击「重新接入 AI」继续，无需删除或重开。改动与限制见 [V0.8 核心说明](docs/V0.8-AI-CORE.md)，本机与真实模型验证见 [V0.8 验收](docs/QA-V0.8.md)。

V0.7 合入用户提供的前端优化版，支持暖白与深色主题，并补齐收藏、作者主页、公开资料编辑、接续提醒、分享管理与编辑、来源路径和内容反馈处理。发现可搜索问题、成果文字和作者，列表与接续成果均支持分页。完整设计与接口见 [V0.7 社区说明](docs/V0.7-COMMUNITY.md)，实际验证见 [V0.7 验收](docs/QA-V0.7.md)。

V0.6.1 在提问、回答、随手记和岔开的念头中加入普通话语音输入。点击麦克风后才开启识别，确认文字追加到原稿，停止后可修改再提交。识别由浏览器提供，可能联网处理声音；本应用不保存录音。浏览器不支持、权限拒绝或识别服务失败时会给出提示。详见 [语音输入与验收](docs/VOICE-INPUT.md)。

V0.6 已接入 V0.5.2 的认知质量基线，并完成账户、服务端公开卡片存储和社区最小闭环：**甲分享确认过的成果 → 乙从同一问题独立思考 → 乙选择分享 → 甲看到新的分支**。

完整对话、随手记、分析和调用记录不会进入社区卡片。模型辅助分析会把当前问题、相关回答和认知状态发送给配置的模型服务商；这与公开分享到社区是两条独立的数据路径。

## 启动

需要 **Node.js 24.13 或更新版本**。当前 SQLite 使用 Node 内置模块，Node 24 会提示实验性警告。

```bash
npm ci
npm run build
npm start
```

打开终端显示的地址。Windows 运行包完整解压后可直接运行 `启动项目.bat`；源码包首次运行会安装依赖并构建。源码开发可使用 `npm run dev`，测试使用 `npm test`。本地目录名仍保留 `reflective-journey-v0.4`，应用版本为 0.10.0，个人思考 schema 保持 5。

有旧 `.env.local` 时继续使用；首次配置可将 `.env.example` 复制为 `.env.local`。不要覆盖已有密钥。首页默认「AI 共同思考」，也可主动选择「本地提纲」。没有模型配置、连接失败或达到限额时会明确提示，不再自动回退。直连此电脑的 localhost 访客可使用已配置模型；代理和公网访问仍须登录，发布卡片始终须登录。

## 这一版可以做什么

- 自己提出问题，由 AI 结合实际表达选择每轮目标，并提供有内容的回应和一个聚焦的追问；程序检查真实引文、重复和状态写入。
- 使用随手记、90 秒停顿询问、提示、成果整理和现实验证回看。
- 注册或登录账户，分别保存此浏览器中的个人记录、草稿和笔记。
- 在账户页主动选择带入旧访客记录，原访客记录保留。
- 整理成果后逐项选择公开字段、修改公开文本、查看预览并确认发布。
- 在「发现」中搜索、分页、打开分享链接，查看一张卡片的来源和接续成果。
- 从卡片的问题开始自己的思考；新会话不继承作者立场、分析和已完成动作。
- 查看「我的分享」，撤回公开；反馈内容问题，由服务器运营者处理。
- 展开更早来源和多层接续路径；从成果及历史记录回到来源或自己已分享的副本。

没有加入点赞、关注、排名和评论。

## 保存与隐私边界

| 内容 | 保存位置 | 访问方式 |
| --- | --- | --- |
| 完整对话、草稿、随手记、分析与调用记录 | 此浏览器 localStorage，按账户分开；访客保留旧键 | 当前工作区查看和导出，不自动同步到其他设备 |
| 账号、口令派生值、登录会话 | 服务端 SQLite | 登录接口校验；口令不明文保存，Cookie 为 HttpOnly |
| 用户预览并确认的卡片副本 | 服务端 SQLite | 公开后任何知道地址的人可阅读；只能发布允许的成果字段 |
| 内容反馈和运营处理记录 | 服务端 SQLite | 反馈本人和获授权运营者可查看；普通账户不能读取他人的反馈 |

账户切换只提供产品内的工作区隔离，不等于此设备上的加密保管。共用设备仍应使用各自的浏览器配置。清理浏览器数据可能丢失个人思考，请及时导出。登录同一账户不会自动取回另一设备的私密对话。

撤回后，发现页和公开接口不再提供该卡片，作者仍可在「我的分享」查看副本；其他人已复制、导出或缓存的内容无法自动收回。子分支不再展示已撤回来源的作者和题目，但保留自己的成果。

旧 V0.2–V0.4 数据沿用原迁移机制；V0.5 的访客记录不自动归入新账户。逐项带入不会上传完整记录。

## 服务端配置

`.env.example` 给出所有配置项。API Key 只在服务端使用，不要放入 `VITE_*` 变量。

| 配置 | 默认 / 说明 |
| --- | --- |
| `COMMUNITY_DB_PATH` | `./data/community.sqlite`，需放在持久可写磁盘 |
| `COMMUNITY_INVITE_CODE` | 留空可注册；设置后需要邀请码 |
| `COMMUNITY_MODERATOR_IDS` | 推荐：已核对的运营账户完整 ID，逗号分隔；默认留空 |
| `COMMUNITY_MODERATOR_USERS` | 兼容旧配置：仅在启动时绑定已有账号；未建立的配置名禁止公众注册 |
| `APP_ORIGIN` | 本机可留空；部署时填写实际网站来源，如 `https://example.com` |
| `COOKIE_SECURE` | 本机 HTTP 为 false；HTTPS 来源会自动使用 Secure Cookie |
| `AI_DAILY_LIMIT` / `AI_MINUTE_LIMIT` | 每账户每日 80 / 每分钟 8 次 |
| `AI_GLOBAL_DAILY_LIMIT` | 全站每日 500 次，防止新账户绕过账户上限 |
| `AI_ALLOW_LOCAL_GUEST` | 默认允许严格校验的本机直连访客使用模型，false 关闭；公网或带代理头的请求仍须登录 |
| `AI_LOCAL_ONLY` | true 禁用模型，用户可选择本地提纲 |
| `DEEPSEEK_THINKING_MODE` | 默认 disabled；enabled 启用服务商思考模式并增加输出预算与等待时间 |
| `RJ_ARENA_TOKEN` | 可选的本机模型竞技场凭据，不发送给浏览器 |

每日额度在 UTC 00:00 重置，账户页显示本地时间。V0.8 对话一轮通常占一次模型调用，理解、决策、回应一起返回；候选未通过质量检查时最多再请求模型修正一次，并计入额外额度。主动检查连接占一次；竞技场按 Provider 数量预留。失败请求也可能已预留额度。本机访客受全站每日及本机每分钟额度约束。每账户最近 24 小时最多发布 20 张卡，登录、注册、发布和反馈另有频率限制。额度约束调用次数，不是精确的金额预算。

保留已有 DeepSeek、OpenAI、GLM 或自定义兼容接口配置，模型名以账户实际可用配置为准。通过首页「模型连接」查看服务端检测到的配置。

配置存在不代表连接成功。「模型」页的「测试真实连接」发送独立合成请求；思考页只有实际成功后才显示模型参与。若提示运行环境禁止外网访问，请在有正常网络权限的终端中启动服务。

## 构建和运行

```bash
npm test
npm run build
npm run serve -- --host 127.0.0.1 --port 5174
```

`serve` 同时提供 `dist/` 和账户、社区、AI 接口。仅上传 `dist/` 到静态托管无法运行社区。开发和预览命令也接入同一后端。此轮只完成本地版本，没有部署到公网。

小范围试用可用独立 Node 进程、HTTPS 反向代理和持久磁盘。设置正确的 `APP_ORIGIN`，保留原始 Host；代理后登录限速目前按连接 IP 计算，应在代理侧补充限流。SQLite 适合当前单实例内测；多实例部署需要共享数据库、共享限流和进一步运维设计。

可运行 `npm run backup` 在线备份数据库，快照包含已提交 WAL 数据，校验后形成一个独立文件。默认保存到数据库旁的 backups 目录，仅保留本工具同源的最近 30 份。恢复前先停止所有访问此数据库的服务，再运行 `npm run restore -- --backup "备份文件路径" --confirm-stopped`，工具会先保留恢复前副本。个人会话和笔记仍需从浏览器单独导出。`.env.local` 另行保管，数据库、密钥和测试数据不会进入提交包。

目前没有邮件验证、找回密码或账户注销。社区运营网页通过服务端固定账户身份授权，普通账户不能处理反馈。需要运营账户时，先正常建立并核对账户，再配置其 ID 并重启；网页不能授予角色。这一版适合受邀内测，尚未完成公开运营所需的账户服务和运维验收。

## 内容反馈处理

仅服务器运营者在本机执行，脚本使用与网站相同的数据库配置：

```bash
npm run moderate -- reports
npm run moderate -- review <反馈ID> keep "核查后的处理说明"
npm run moderate -- review <反馈ID> withdraw "停止公开的处理说明"
npm run moderate -- withdraw <卡片ID> "处理原因至少四字"
```

review 会记录处理说明，让提交者在“我的反馈”查看结果；withdraw 会停止公开并保留作者副本。反馈列表支持 pending / resolved / all 状态和分页游标。网页运营接口需要服务器配置的运营账户。需要定期检查，不能将它当成自动内容审核。

## 模型竞技场

服务端和命令行读取同一份 `.env.local` 中的 `RJ_ARENA_TOKEN`。通过 `RJ_DEV_URL` 指向网站地址，随后执行 `npm run arena`。竞技场会真实调用所有已配置 Provider，使用合成示例而非个人记录，并受全站额度限制。

自动化验收使用本机模拟 Provider，不消耗真实模型额度。

## 关键代码与验收

- `src/lib/engine.ts` / `ai.ts`：认知引擎与模型编排。
- `server/dialogue-turn.mjs` / `ai-access.mjs`：AI 自主决策协议、原话与质量检查、本机访问边界。
- `server/application.mjs` / `community-store.mjs`：账户、权限、限额和持久存储。
- `src/components/ShareDialog.tsx`：选择、编辑和确认公开内容。
- `src/lib/workspace.ts` / `storage.ts`：本机账户工作区和旧记录带入。
- `server/serve.mjs` / `scripts/moderate.mjs`：运行服务与内容处理。
