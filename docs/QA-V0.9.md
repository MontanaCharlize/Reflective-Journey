# V0.9 本地提交验收

日期 2026-10-19。本版以 V0.8.1 为主干，保留核心对话、社区和成果导图。按用户最终选择交付本地项目，通过百度网盘提交文件；本轮没有重新部署或验收公网环境。

## 源码检查

npm test：133 项通过，0 失败、0 跳过。TypeScript 与生产构建通过。新增5项部署备份测试和2项发布文件清单测试，覆盖健康检查、WAL 备份、恢复前副本、无效备份拒绝、保留规则，以及密钥和私密资料排除。

备份使用 node:sqlite 模块的 backup 函数。新快照在校验前切换为独立文件，避免需要额外 WAL/SHM 文件才能读取。恢复前要求停服，先保留目标库副本，再通过 SQLite 完成恢复；不手动删除正常使用库的旁路文件。

## 实际进程与业务恢复

在独立数据库和随机本机端口启动真实生产服务，使用两个独立 Cookie 客户端完成注册、公开卡片发布、独立接续成果发布、收藏、资料更新、公开编辑版本检查与接续提醒。另一个账户不能修改作者卡片，夹带私密字段的发布请求被拒绝。

服务运行时创建在线快照，然后终止并重新启动生产进程。账户会话、卡片版本、作者资料、收藏及提醒仍保留。之后撤回卡片并确认公开读取和收藏过滤生效，再停服恢复先前快照。第三次启动后，账户、公开卡片、版本、来源关系、收藏与提醒恢复至快照状态，恢复前副本也存在。

这些数据为虚构验收资料。本轮未消耗真实模型额度，模型对话质量沿用 V0.8 的单独真实验证记录；语音真实转写、真人学习收益和实体移动设备仍不在本轮验收范围。

## 提交包

源码和运行包分别使用明确文件清单，不复制整个工作目录。源码保留 evals 测试样例，排除依赖、构建、私密配置、数据库、个人回放和回退目录。运行包只包含生产构建、服务端、必要维护脚本、配置示例与官方 Windows x64 Node 运行程序。

Node.js 24.13.1 运行压缩包从 nodejs.org 下载，已按同目录官方 SHASUMS256.txt 校验。随运行版保留 Node 的 LICENSE 和来源记录。最终材料中的解压验收记录另行列出，不能把源码测试直接当作分发包验证。

Docker、Caddy、systemd 文件作为后续部署资产保留，已修正原包的备份 API 和 evals 排除问题；本机没有实际运行 Linux 容器或办理正式域名部署，不将配置存在等同于已部署。
