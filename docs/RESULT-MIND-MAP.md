# V0.8.1 成果思维导图

完成一次思考并确认保存后，成果页可以在「文字成果」和「思维导图」之间切换。已有成果也适用，不需要重开对话或重新请求模型。

导图以原问题为中心，只呈现已保存的初始想法、当前判断、发现、疑问、变化、转折与验证计划。没有填写的字段不生成节点。验证回看作为计划的后续分支呈现，保留每次观察和修订，原成果不被最新回看覆盖。

## 操作

- 拖动画布移动；放大、缩小或点击「适应画布」。键盘方向键可移动画布，Home 键复位。
- 点击节点在下方读取原文。较长文字在画布上最多预览七行，原文面板完整保留。
- 可以收起内容、展开全部或收起选中的节点。点击收起的节点会将它展开。
- 「导出图片」保存 PNG，「SVG」保存可缩放的矢量文件。导出始终包含所有分支的完整原文，不受当前折叠和缩放影响。内容过长、无法清晰生成 PNG 时，提示改用 SVG。

## 数据与实现

从 session.summary、session.verification 和原问题直接生成，使用浏览器 SVG 绘制。没有新增依赖、服务端接口或模型请求，也不改变会话 schema。导图不会读取原始对话、随手记或模型分析来补充未确认的判断。导出发生在本机，不会自动公开到社区。

这版按已保存字段组织分支，不新增“证据支持结论”等推断关系。还没有提供拖动改结构、直接改写节点、AI 自动归纳或把导图发布到社区的入口。需要修改成果时，应先在相应编辑流程中确认；导图跟随保存后的数据展示。

主要代码：src/lib/mind-map.ts、src/components/ResultMindMap.tsx、src/components/Completed.tsx。
