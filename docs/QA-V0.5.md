## 浏览器

使用 Tabbit 在真实浏览器中验证，测试时拦截外部模型请求：

- 提出问题后正常显示第一问，尚未回答的动作不会被标记完成。
- 输入草稿后暂停并重新打开，草稿恢复。
- 回答「不知道」后展示支撑反馈，保持原动作，提示与换个问法可使用。
- 模型尚未返回时刷新，原话和待处理状态保留；重新处理后原话仅出现一次。
- 用户编辑并确认成果，可选验证计划保存后出现在首页。
- 回看结果保存后，刷新并从历史重新打开仍能读取；原有成果保留。
- 手机宽度下核对首页及回看页面，无横向溢出，开发用模型入口隐藏；已检查手机首页截图。
- 页面切换返回顶部，新追问和成果整理可滚动到当前内容。
