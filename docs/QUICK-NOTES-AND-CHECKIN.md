# V0.5.1：随手记与停顿支撑

## 目标与边界

沉默可能是深入思考、走神、卡住或在写别的东西。系统不推断是哪一种，而是提供一个低压力的询问，让用户自己决定接下来做什么。

本版仍使用 schemaVersion 5 和原有会话键，新字段为可选项，不要求迁移现有 V0.5 记录。

## 随手记

- 所有页面右下角可打开；切换首页、思考、历史、成果与模型页时保持。
- 拖动标题区域移动窗口，拖动右下角调整宽高；方向键也可移动/缩放，Shift 加快。
- 可展开到视口内，再恢复之前的尺寸；收起后内容保留。
- 自动保存文字、位置、大小与打开状态，视口改变时将窗口约束在可见区域。
- 单独导出为文本；笔记不自动进入模型上下文，也不自动成为用户回答。
- 本地存储失败会显示未保存提示，当前页仍保留正在输入的内容。

## 停顿询问

只在当前追问等待用户回答时计时。90 秒没有输入、键盘、点击或聚焦活动后，在回答栏下方显示「这一刻，你的思绪到了哪里？」。

全页面输入，包括随手记编辑，会重置计时。拼音组合输入期间不询问；页面隐藏、模型正在处理、首次提问尚未生成和成果整理期间也不询问。重新进入可见页面后重新计时，不立即追问。

询问不弹窗、不自动聚焦、不滚动页面。每个问题在本次停留至多询问一次，并保存最近 200 个已询问问题的标记，减少刷新或重新进入后的重复。可以通过回答栏下的勾选项关闭，选择在浏览器中保留。

## 用户的选择

1. 「我还在想，先别打扰」：本题收起询问，保留回答。
2. 「卡住了，给点提示」：使用当前动作的本地提示，不发起额外模型请求。
3. 「有了别的想法」：打开小输入区，自动保存该会话的侧思路草稿。

侧思路可以：

- 放进回答草稿，由用户点击继续思考后再提交。
- 追加到全局随手记，带上原问题作记录背景。
- 另存一个新思考方向；新会话保存来源记录和原问题，可返回原来的问题。原问答和草稿保留。

用户主动收起侧思路后，不在刷新时自动展开；未完成的草稿提供「接着记刚才的想法」入口。

回答栏下也有「先记一个岔开的念头」入口，用户可以随时主动记录，不必等待 90 秒。在侧思路输入区展开时暂停停顿计时，关闭后再开始。

## 数据与验证

随手记、询问偏好与已询问标记独立存储在 reflective-journey/v0.5 下。侧思路沿用按会话隔离的草稿。分支来源包含在 JSON 和 Markdown 导出中。

自动化覆盖窗口边界、保存失败、追加保留、90 秒阈值、编辑重置、组合输入/隐藏/关闭门控、避免重复、偏好保留，以及分支不覆盖原记录或自动上传笔记。

浏览器验证使用独立的本地测试地址与备用引擎，避免修改正常使用地址的数据或消耗外部模型额度。具体结果记录在 QA-V0.5.1.md。
