# V0.5.1 验证记录

## 已完成

- 42 项自动化检查通过；生产构建及服务端语法检查通过。
- 真实界面中的鼠标拖动和右下角缩放生效，方向键移动/缩放生效。
- 输入笔记后跨页与刷新，文字、位置和大小均恢复。
- 展开后可恢复之前尺寸。

## 界面验证通过

- 实际静默后出现温和询问，回答草稿保留；90 秒精确阈值由自动化覆盖。
- 继续在随手记中编辑，会收起已经出现的询问；该输入通道被识别为编辑活动。
- 侧思路追加到回答时保留原有文字，不直接提交。
- 侧思路追加到全局笔记时保留既有笔记，并保存原问题作背景。
- 沿新念头创建单独会话后，可返回原问题，原回答及两个方向的草稿保留。
- 刷新后未完成的侧思路以轻量入口恢复，不强制展开。
- 关闭停顿询问后，刷新并重新打开会话仍保持关闭。
- 390px 手机宽度下，窗口调整到可见范围，文字与关闭/缩放控件可用。

Tabbit 创建新页面失败后，使用应用内浏览器完成以上检查。测试页面来自独立静态预览，API 固定回退本地引擎，未消耗真实模型额度。测试记录与用户正常地址的数据隔离。

测试地址与正常使用地址分离，测试 API 固定使用本地备用引擎。自动化和界面验证不代表已经证明用户注意力、回答意愿或复访效果改善。
