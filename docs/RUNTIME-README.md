# 反思之旅 Windows 运行版

完整解压后，双击「启动项目.bat」即可使用。运行包已包含构建好的页面、服务端和官方 Node.js，不需要安装依赖或重新构建。使用期间保留启动窗口；需要停止新启动的服务时按 Ctrl+C。

默认地址为 http://127.0.0.1:5174/。再次启动时，如果该地址已有反思之旅服务，程序会显示服务版本并打开已有页面。终端会说明此次没有启动当前目录的新副本。建议固定使用原地址和浏览器，避免误以为原来的个人记录丢失。

## 也可以从终端启动

有 npm 的电脑可使用 npm start，npm run dev 和 npm run serve 也会启动这个已构建的本地应用。它们不会启动 Vite 开发服务器，不会自动换到另一个端口。

需要同时运行另一份副本时，在当前运行版目录执行：

```text
.\启动项目.bat --port 5177
```

浏览器完整会话、随手记和草稿按地址分别保存，5177 不能直接读取 5174 的浏览器记录。请不要通过改端口找回旧记录；先回到原地址查看。服务端账户和社区数据保存在各自配置的 SQLite 数据库中。

## 测试和构建要使用源码包

运行版不包含 src、tests 和 TypeScript 配置。这里的 npm test 和 npm run build 会明确提示改用源码包，并以失败状态结束，不会把“0 项测试”显示成验收通过。

要检查源码，请另行解压同版本的「源码.zip」，进入有 src、tests、tsconfig.json 的目录，再运行 npm ci、npm test 和 npm run build。不要把源码复制到正在使用的运行版目录。

## 配置真实模型

运行包不含作者的模型密钥。可将 .env.example 复制为 .env.local，填写自己的服务端 API Key 后重启。已有 .env.local 不要覆盖。没有配置模型时，可在首页主动选择「本地提纲」。

完整会话和随手记需要从页面单独导出备份；数据库备份不能代替浏览器记录导出。数据库维护方式见 docs/LOCAL-RELEASE.md。
