# V0.6：独立的思考分支

## 完成的三个阶段

1. 将提供的 V0.5.2 认知质量改动合入当前 Windows 项目，在目标环境实际跑通原有 63 项检查和生产构建。
2. 增加真实账户、登录会话、SQLite 持久存储、服务端访问权限和模型调用额度。
3. 增加预览确认分享、发现与搜索、公开链接、独立接续、成果回流、撤回和内容反馈处理。

新增 15 项检查后共 78 项。之前对话中的 V0.5.2 测试数量来自外部包；这次的数量来自本机执行。界面和后端均已有实现，不是浏览器内模拟数据。

## 用户流程

```text
甲：个人思考 → 整理并确认成果 → 逐项选择公开内容 → 编辑与预览 → 确认发布
                                                                ↓
乙：发现或分享链接 → 阅读卡片 → 从问题开始新会话 → 形成自己的判断 → 自选分享
                                                                ↓
甲：原卡片 → 从这里展开的思考 → 查看乙的独立分支
```

乙的会话只从问题和来源信息开始，`currentPosition` 为空、`completedMoves` 为空，第一问为表达自己的判断。不会复制甲的答案、分析、策略记录和完成状态。乙的公开成果通过 `sourceCardId` 关联原卡片。

## 数据模型

服务端使用 `server/community-store.mjs` 的 SQLite 数据库，启用 WAL、外键和事务。

| 表 | 内容 |
| --- | --- |
| users | 随机 ID、唯一账号、展示名称、随机盐、scrypt 口令派生值 |
| sessions | 登录令牌的 SHA-256 摘要、用户、7 天有效期 |
| cards | 作者、公开问题、允许的成果字段、来源、公开状态、幂等键与载荷摘要 |
| ai_usage / ai_minutes | 每账户每日与每分钟调用预留 |
| global_ai_usage | 全站每日调用预留 |
| reports | 每用户每卡片一条反馈，可更新原因 |
| moderation_actions | 本机运营者停止公开的原因与时间 |

浏览器中的 `ThinkingSession` schema 仍为 5，新增可选的 `communitySource`。旧访客键继续保留；账户键为 `reflective-journey/v0.6/users/<userId>/<内容名>`。随手记、草稿、偏好、停顿设置和个人会话均使用当前工作区的键。

这不是完整的私密数据云同步。工作区隔离也不是浏览器本地加密。共同使用同一设备的人应使用各自的浏览器配置。

## 公开字段与权限

公开载荷只接受 `question`、`fields`、`sourceCardId`、`clientKey`。`fields` 白名单为：

`initialJudgment`、`currentJudgment`、`keyDiscovery`、`openQuestion`、`changed`、`nextAction`、`expectedSignal`。

每个字段最多 2400 字符，公开问题最多 600 字符。发布窗口初始不勾选任何字段，编辑后必须重新确认；后端拒绝额外字段和伪造作者，作者从登录会话取得。相同幂等键和相同内容重试返回已有卡片，改动内容或撤回后再次复用会被拒绝。

未登录可读公开卡片，不能发布、撤回、反馈或调用付费模型。卡片仅作者能在正常接口撤回；撤回后公开读取返回 404，作者仍可读自己的副本。子卡片仅显示来源不可用，不返回已撤回来源的作者和题目。

公开接口只提供作者 ID 和展示名称，不提供登录账号、口令、会话、举报者信息。公开快照不包含全文对话、笔记、分析、调用日志；模型辅助分析另会把当前思考所需上下文发往配置的模型服务商。

所有 POST 校验 Origin，账户 Cookie 为 HttpOnly、SameSite=Lax，HTTPS 使用 Secure。前端提交当前工作区 ID，后端比对 Cookie 所属账户，避免其他页面切换账户后将旧内容发到新账户。前端取消旧请求，并在异步完成时检查工作区归属。

## 接口

响应为 JSON，错误含 `code`、`message`；全部 API 响应禁止缓存。POST 需要同源 JSON 和登录 Cookie（注册、登录除外）。

| 方法和路径 | 用途 |
| --- | --- |
| GET `/api/account/me` | 当前账户、剩余额度、是否要求邀请码 |
| POST `/api/account/register` | username、displayName、password，可选 inviteCode |
| POST `/api/account/login` | username、password |
| POST `/api/account/logout` | 撤销当前会话 |
| GET `/api/community/cards?q=&cursor=&limit=` | 公开发现、问题搜索、游标分页 |
| GET `/api/community/mine` | 当前作者最近 100 张公开或撤回卡片 |
| POST `/api/community/cards` | 发布经预览确认的卡片副本 |
| GET `/api/community/cards/:id` | 卡片、可公开来源、最近 40 条公开接续成果 |
| POST `/api/community/cards/:id/withdraw` | 作者撤回 |
| POST `/api/community/cards/:id/report` | 登录用户反馈，载荷 reason |
| GET `/api/ai/providers` | 已配置模型的公开元信息 |
| POST `/api/ai/analyze`、`/question`、`/arena` | 登录并受额度限制的模型调用 |

网页路由用 `/#/community/<id>`，刷新或复制链接都会重新读取服务端。服务器必须同时提供静态资源和接口。

## 运营与交付边界

运行和配置见根目录 README；`npm run moderate -- reports` 查看最近反馈，`npm run mode rate -- withdraw <id> "原因"` 停止公开并记录原因。脚本依赖服务器数据库文件权限，没有公开管理员接口。

支持当前单实例、受邀内测。尚未完成真实用户复访、两台实体设备、公网 HTTPS、邮件验证、密码找回、账户注销、多实例和自动审核验证。首次公开运营前需要补足这些账户和运维能力，并用真实 Provider 做连续会话质量评估。

相关证据见 [本机验收记录](QA-V0.6.md)。
